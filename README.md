# 臺灣各縣市出生與死亡 BI 網頁

把內政部戶政司的月報（出生、死亡、結婚、離婚，按登記日期）整理成可互動篩選的網頁。

- 網頁：https://tstyphoon.github.io/tw-births-deaths/
- 資料期間：民國 100 年 1 月至 115 年 8 月（西元 2011–2026），22 個縣市，共 188 個月

## 資料來源

內政部戶政司人口統計資料：「出生數、死亡數按性別及結、離婚對數按區域別分（按登記日期）」。
`raw/` 是從網站下載的原始 Excel（每年一個檔，每月一個工作表），沒有修改過。

## 目錄

```
raw/                  原始檔：16 個 .xls（民國 100–115 年）
etl/etl.py            ETL：xls -> data/monthly.csv，並做加總核對
etl/build_data.py     把 CSV 整理成網頁用的 docs/data.js
data/monthly.csv      整理後的月資料（UTF-8 with BOM，可直接用 Excel 開）
data/region_mapping.csv   縣市所屬區域與類型（人工分類）
data/validation_report.txt  ETL 驗證結果
docs/index.html       BI 網頁（單一檔案，雙擊即可開啟）
docs/data.js          網頁載入的資料
```

重新產生資料：

```
uv run etl/etl.py
uv run etl/build_data.py
```

## data/monthly.csv 欄位

每列是「月份 × 縣市」。

| 欄位 | 說明 |
|---|---|
| year_roc, year_ad, month | 民國年、西元年、月 |
| region | 縣市（桃園縣於 103/12/25 改制，統一寫成桃園市） |
| area | 區域：北部、中部、南部、東部、離島（人工分類） |
| region_raw | 報表上的原始名稱 |
| births_total / births_male / births_female | 出生數（合計、男、女） |
| births_legit / births_nonlegit | 婚生、非婚生（已認領＋未認領） |
| deaths_total / deaths_male / deaths_female | 死亡數（合計、男、女） |
| marriages / divorces | 結婚對數、離婚（終止結婚）對數，不分性別 |

## ETL 處理了哪些髒資料

- 報表是合併儲存格：每個縣市佔 3 列（計、男、女），名稱只寫在其中一列。
- 各年欄位數不同（15 欄、17 欄、21 欄），所以依表頭文字找欄位，不寫死位置。
- 108 年 5 月以前，結婚、離婚的數字寫在「男」那一列；之後寫在「計」那一列。
- 桃園縣在 103 年 12 月改制為桃園市，視為同一個縣市；改制前桃園縣屬臺灣省，驗證時也依此處理。
- 排除全國總計、臺灣省、福建省這三列（只用來核對），以及表格下方的「說明」。
- 各年的全年累計表、縣市全年出生率表不納入月資料，累計表只用來核對。

## 驗證（`data/validation_report.txt`）

1. 出生、死亡：男 ＋ 女 ＝ 合計
2. 22 縣市加總 ＝ 報表的全國總計（出生、死亡、結婚、離婚，每個月）
3. 臺灣省、福建省 ＝ 轄下縣市加總
4. 民國 104–114 年：12 個月加總 ＝ 全年累計表

## 限制

- 統計的是「登記日期」，不是實際發生日期；延遲登記與假日會影響月份之間的高低。
- 民國 115 年只有 1–8 月，年度合計若包含 115 年會比其他年份少。
- 沒有人口數，所以只有人數與對數，沒有出生率、死亡率；縣市之間不能直接比較高低。
- 區域分類是人工判斷。
